About the Project

The LEGO Train Logic Game represents the perfect fusion of physical play and digital innovation. Our project transforms traditional LEGO train sets into an interactive, intelligent gaming platform that challenges players with real-world logic puzzles.

Using ESP32 microcontrollers, sensors, and Home Assistant integration, we've created a system where physical train movements trigger digital responses, creating an engaging bridge between the tangible and virtual worlds.

The Game Experience

How It Works

Players are presented with logic puzzles that must be solved by strategically moving LEGO trains through a track system. Each movement is detected by sensors and processed by our smart system, providing real-time feedback and validation.

1

Analyze the Puzzle

Study the track layout and understand the objective

3

Execute & Learn

Move the trains and receive instant feedback

Technical Specifications

Hardware Components

ESP32 Microcontroller

Main processing unit with WiFi capabilities for Home Assistant integration

Proximity Sensors

Detect train positions and movements with high accuracy

LEGO Train Motors

Controlled via PWM signals for precise speed and direction control

Track Sensors

Monitor train locations throughout the track system

Software Stack

Arduino Framework

ESP32 programming environment for hardware control

Home Assistant

Central automation hub for device coordination

MQTT Protocol

Lightweight messaging for real-time communication

Web Interface

HTML/CSS/JavaScript for user interaction and monitoring
